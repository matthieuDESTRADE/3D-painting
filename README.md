# 3D reconstruction of Van Gogh's Church at Auvers-sur-Oise

This repository contains an OpenGL scene bringing Van Gogh's Church at Auvers-sur-Oise painting to life in 3D, using a cloth-like physical simulation to animate the sky, ground, and grass along with a hierarchically animated character. It uses the [CGP](https://graphicscomputing.fr/cgp/documentation/01_general/index.html) library.

To run the prepared build of the scene directly, open: [scene/scene.exe](scene/scene.exe). It is possible to rotate the camera around the scene by left-clicking and dragging, and zoom in or out by right-clicking and dragging.
